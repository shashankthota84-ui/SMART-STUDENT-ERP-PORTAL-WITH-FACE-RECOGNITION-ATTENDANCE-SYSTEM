# Tests

## Testing Approach
The project was tested manually by checking the webcam, face detection flow, navigation, responsiveness, and user messages.

## Test Cases
- Checked if the website opens correctly
- Checked if webcam permission is requested
- Checked if the webcam starts after permission is allowed
- Checked if face detection works when a face is visible
- Checked if error message appears when no face is detected
- Checked if verification success message appears when face matches
- Checked responsive design on desktop and mobile screen sizes
- Checked navigation between pages

## Results
The main face recognition flow works as expected under proper lighting and camera conditions.

## Known Issues
Face detection may be affected by poor lighting, blurry camera quality, or partially covered faces.
