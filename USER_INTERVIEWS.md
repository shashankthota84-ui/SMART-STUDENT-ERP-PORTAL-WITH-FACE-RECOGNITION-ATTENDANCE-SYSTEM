# User Interviews

## Interview Goal
The goal of user interviews is to understand whether users need a face recognition system and what features they expect.

## Questions Asked
1. Do you currently use any login or attendance system?
2. What problems do you face with the current method?
3. Would face recognition make verification easier?
4. What concerns do you have about privacy or security?
5. What features would make this system more useful?

## Key Insights
Users want a system that is fast, simple, accurate, and easy to use.

## Feedback
Users preferred a clean interface, clear webcam instructions, fast verification, and proper error messages.

## Improvements Based on Feedback
- Add better instructions before starting webcam
- Show clear success and failure messages
- Improve mobile responsiveness
- Add privacy and security information
