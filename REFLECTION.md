# Reflection

## What We Learned
Through this project, we learned how face recognition can be implemented in a web application using React, JavaScript, HTML, and CSS. We also learned how to work with webcam permissions and browser-based face detection.

## Challenges
The main challenges were webcam access, face detection accuracy, lighting issues, and maintaining a smooth user experience.

## Improvements
In the future, this project can be improved by adding backend authentication, database storage, better face matching accuracy, liveness detection, and stronger security.

## Final Thoughts
This project helped us understand real-world authentication systems and how artificial intelligence features can be integrated into frontend web applications.
